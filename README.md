# 💰 Expense Manager

A beginner-friendly Python CLI application for tracking daily expenses.

## ✨ Features

- Add expenses
- View all expenses
- Calculate total spending
- Check spending by category
- Delete expenses
- Persistent JSON data storage
- Input validation and basic error handling

## 🛠️ Technologies

- Python 3
- JSON
- pathlib
- File handling

## 📁 Project Structure

```text
Expense-Manager/
├── main.py
├── README.md
├── requirements.txt
├── .gitignore
└── expenses.json
```

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python main.py
```

The application automatically creates `expenses.json` when you add your first expense.
